# EcoScan — Sitio Web Oficial

> **"La posibilidad de mejorar el mundo al alcance de tu mano"**  
> Landing page oficial para la presentación y descarga directa de **EcoScan**, la aplicación Android para clasificación inteligente de residuos con visión artificial y Edge AI sin conexión a Internet.

---

## Características de la Web

- **Identidad Visual Propia:** Diseñada con una estética nativa Android de cristal líquido (*Backdrop Liquid Glass*), verdes orgánicos y contrastes calculados para alta legibilidad.
- **Demostración Interactiva:** Mockup de smartphone Android con selector de pantallas reales (Scan en vivo, Centro de Información, Ajustes).
- **Selector Multinorma de América Latina:** Adaptación interactiva en tiempo real a las legislaciones oficiales de 7 países (Argentina, Brasil, Chile, Colombia, México, Perú, Uruguay).
- **Descarga Directa de APK:** Enlace directo de descarga vinculado a los releases oficiales de GitHub ([EcoScan-Releases](https://github.com/samd27/EcoScan-Releases)).
- **Accesibilidad y Rendimiento:** WCAG 2.1 AA compliant, soporte para `prefers-reduced-motion`, navegación por teclado con `:focus-visible` y bundle ligero (< 90 kB sin dependencias pesadas).

---

## Tecnologías Utilizadas

- **HTML5 Semántico + WAI-ARIA**
- **Vanilla CSS (Tokens & Glassmorphism System)**
- **JavaScript Moderno (ESModules)**
- **Vite** como empaquetador ultrarrápido

---

## Desarrollo Local

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build

# Previsualizar el bundle compilado
npm run preview
```
